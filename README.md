# HagiiZ 応援サイト（ともプロ！2026）

東北大学主催の選考型クラウドファンディング「ともプロ！2026」No.09 への入口となるサイトです。
GitHub Pages でそのまま公開できます。

## ページ構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップ。模型 → 30秒でわかる → 寄付でできること → 数字 → 動画 → 3つの物語 → 届くもの・寄付のしかた → よくある質問 → 最後のひと押し |
| `science.html` / `doboku.html` / `bosai.html` | 分野ごとの物語。縦に読みます |

## 見る人に起きること

- **書体は3段**：見出し・数字は Dela Gothic One、言い切りの一文は Noto Sans JP の極太、説明はふい字（無ければ Zen Kurenaido）。
- **倍速モード**：物語ページの「⚡倍速」で、主張と見出しだけになります（約2〜3分）。`science.html?fast=1` のようにURLで最初から倍速にもできます。
- **上のバー**：場面ごとに読んだ量が伸び、「のこり約◯分」が出ます。
- **寄付ボタンは日付で自動で変わります**
  - 10/1より前：「10/1の開始を予定に入れる」（Googleカレンダーに登録）
  - 10/1〜11/30：「寄付する」
  - 12/1以降：「寄付ページで結果を見る」
- 締切7日前から、残り日数のバッジが赤く点滅します。
- スマホでは、最初の画面を過ぎると画面下に寄付バーが出ます。

## 本文の書き方（content/*.js）

- `{ ... }` の1つが1つの場面です。`body` の `"..."` が1段落。改行は `\n`。
- **段落まるごと `**…**` で囲むと「主張」**（太いゴシック・マーカー付き）になり、倍速モードでも残ります。
- 段落の一部だけ `**…**` にすると、その部分が太字＋マーカーになります。
- `tldr` は表紙の「3行でいうと」です。
- 〔OO〕のような未記入は、制作中は黄色で目立ち、公開時（`DRAFT: false`）は自動で隠れます。

## 設定（assets/js/config.js）

| 項目 | 内容 |
|---|---|
| `DRAFT` | 制作中は `true`、**公開時は `false`** |
| `GOAL` | 目標額。**寄付ページの「目標金額」と必ず揃える** |
| `FUNDS` / `UNITS` | 使い道の内訳と「◯円で◯◯ができる」。寄付ページの記載と揃える |
| `TEAM_GIFT` / `NAME_FORM_URL` | HagiiZからの特典（名前を刻む）と、名前登録フォームのURL |
| `VIDEO` | 挨拶動画。空のまま公開すると動画の欄ごと隠れます |
| `GA_ID` | Google Analytics 4 の測定ID（任意）。寄付・予定登録ボタンのクリックを位置つきで記録 |

## 支援額の自動更新

`.github/workflows/progress.yml` が毎朝9時半に寄付ページを読み、`data/progress.json` を書き換えます。
サイトはその数字をゲージに使います（寄付ページ側の反映は翌営業日以降です）。

- 初回だけ：リポジトリの **Settings → Actions → General → Workflow permissions** を「Read and write」にしてください。
- すぐ更新したいとき：Actions タブ →「支援額を更新」→ Run workflow。
- 読み取りに失敗しても前回の数字が残るだけで、サイトは壊れません。

## ふい字

`assets/fonts/README.md` を見てください。`tools/subset_font.py` で使う文字だけに絞ると、約3〜4MBが200KB前後になります。

- [ ] `images/ogp/` に共有用画像（1200×630）を置いた
- [ ] 〔OO〕の未記入を埋めた（制作中モードで黄色い箇所）
- [ ] 名前を刻む特典のフォームURLを入れた（または `TEAM_GIFT` を空にした）
- [ ] 目標額・使い道が寄付ページと一致している

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてアップロード（`.nojekyll` と `.github` も含める）。
2. **Settings → Pages** で Source を `Deploy from a branch`、Branch を `main` / `/ (root)` にして Save。
3. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で公開されます。
