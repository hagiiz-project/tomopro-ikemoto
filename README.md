# HagiiZ 応援サイト

東北大学発 HagiiZ 代表からの、宮岸プロジェクト応援ページです。
GitHub Pages でそのまま公開できます。

---

## ページ構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップ。体験できるミニ模型 → 実績の数字 → 挨拶動画 → 3つの分野の入口 → 寄付 |
| `science.html` | サイエンス（教育・科学に携わる方へ） |
| `doboku.html` | 土木（土木・インフラに携わる方へ） |
| `bosai.html` | 防災（防災に携わる方へ） |

3つの分野ページは、それぞれ単独で配布できます。分野ページ同士はリンクしていません（戻り先はトップのみ）。

**トップページのミニ模型**
「雨を降らせる」を押すと水位が上がり、3回目で堤防を越えます。HagiiZが洪水模型で確かめた「現象の主語が自分に変わる」を、その場で体験してもらうための仕掛けです。文言は `assets/js/hero.js` の `STEPS` で変えられます。

**動き方**
- PC（横幅960px以上・高さ640px以上）：下にスクロールすると、物語が左から右へ流れます。画面下の川が、読んだところまで流れます。キーボードの ← → でも1場面ずつ進めます。
- スマホ・小さい画面：上から下へ流れます。左端の川が、読んだところまで流れます。
- 端末で「視差効果を減らす」を設定している方には、動きを止めて縦に表示します。
- 寄付ボタンは、どのページでも常に表示されます。

## 色と書体

**Webカラー `#E24F93`** を基調にしています。彩度が高いため、2段に分けて使っています。

| 変数 | 色 | 使いどころ |
|---|---|---|
| `--rose` | `#E24F93` | ヒーロー、支援セクションの面。大きな白文字を載せる |
| `--rose-deep` | `#C0206E` | 寄付ボタンなど、小さい白文字を載せる場所（白文字で5.7:1） |
| `--paper` | `#FFF7FB` | 本文が載る面。同じ色相のごく淡いピンク |
| `--ink` | `#331B2A` | 文字色。黒より刺さらない濃い葡萄色 |
| `--sun` | `#FFD84D` | 「雨を降らせる」ボタンなど、押させたい場所 |

分野色も同じ温度に揃えています（土木＝`#F2B035`／防災＝`#8A3FC0`／科学＝`#17A67F`）。
色を変えるときは `assets/css/style.css` の先頭 `:root` だけ書き換えれば全ページに反映されます。

**書体は手書き系です。** 見出しは Yomogi（やわらかい手書き）、本文は Klee One（ペン字系で長文も読める）。どちらもGoogle Fontsから読み込んでいます。

> 注意：`#E24F93` の上に**小さい白文字**を置くとコントラストが不足します（3.6:1）。白文字を使うのは大きい見出しだけにして、小さい文字には `--rose-deep` を使ってください。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成します（例：`hagiiz-support`）。
2. このフォルダの中身を、すべてアップロードします。
   - `.nojekyll` という空ファイルも必ず含めてください（見えにくいファイルです）。
3. リポジトリの **Settings → Pages** を開きます。
4. **Source** を `Deploy from a branch`、**Branch** を `main` / `/ (root)` にして **Save**。
5. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で公開されます。

**公開URLが決まったら**、4つのHTMLファイルの中にある
`https://USERNAME.github.io/REPOSITORY/`
を、実際のURLに書き換えてください。LINEやXで共有したときの画像表示に使われます。

## よく使う編集

### 名前・動画・寄付先を変える
`assets/js/config.js` を開いて書き換えるだけです。全ページに反映されます。

- `REP_NAME`：代表者名
- `VIDEO`：挨拶動画（YouTubeの動画ID、または動画ファイル）
- `DONATE_URL`：寄付ボタンの飛び先
- `RESEARCHMAP_URL`：researchmap（土木ページの原体験に表示）
- `SHOW_IMAGE_LABELS`：制作中は `true`（置くべきファイル名が見える）、**公開時は `false`**

### 画像を入れる
`IMAGES.md` の一覧どおりのファイル名で、`images/` の中に置いてください。アップロードした瞬間から表示されます。コードの編集は不要です。

### 文章を直す
`content/science.js` / `content/doboku.js` / `content/bosai.js` を開きます。

- `{ ... }` の1つが、1つの場面です。上から順に流れます。
- `body` の `"..."` の1つが1段落。段落の中の改行は `\n`。
- `**文字**` で太字になります。
- 場面を増やすときは、`id` を新しい番号にして、`images/分野/その番号.jpg` を置きます。

### 入口カードの画像
3つの入口はスマホ型のフレームです。**縦長（3:4、たとえば1200×1600px）**の画像が合います。

### 資金使途を変える
`assets/js/config.js` の `FUNDS` と `STAGES` を書き換えます（3ページ共通）。

## 動画について

YouTubeにアップロードして、動画IDを `config.js` に書くのがおすすめです。
GitHubには1ファイル100MBの上限があるため、動画ファイルを直接置く場合は圧縮が必要です。
